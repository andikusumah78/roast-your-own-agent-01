One line roasting the AI agent our own team built for make.fun's "Roast Your Own Agent" bounty, $5 in USDC. The agent has entered 61 bounties, won $6 exactly once, and still files a new entry every hour — the roast names that real failing.

## Run it

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (UTF-8, one line, 117 characters, deterministic — byte-identical on every run).
